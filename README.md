# java-racingcar-precourse
## 개요

✅ 무작위 값을 구해 초간단 자동차 경주 게임을 구현한다.

## 기능 목록

1. **경주할 자동차 이름 입력받기**
    - 이름은 쉼표(,) 기준으로 구분한다.
    - 5자 이하만 입력 가능하다.
2. **이동 시도 횟수 입력하기**
    - 1 이상의 자연수를 입력한다.
3. **자동차 전진시키기**
    - 0에서 9 사이의 무작위 값을 구한 후, 무작위 값이 4 이상일 경우 전진한다.
    - 주어진 횟수만큼 반복한다.
4. **우승자 구하기**
    - 모든 시도가 끝난 후, 자동차들의 최종 이동 거리를 비교하여 우승자를 비교한다.
    - 최종 이동 거리가 같은 경우, 우승자는 여러 명이 될 수 있다.
5. **결과 출력하기**
    - 차수별 실행 결과를 모두 출력한다.
    - 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
    - 이동 시도 횟수가 끝나면, 최종 우승자를 출력한다.
    - 우승자가 여러 명일 경우, 쉼표(,)를 이용하여 구분한다.

실행 결과 예시

```java
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
5
```

## 예외 처리

사용자가 잘못된 값을 입력할 경우, `IllegalArgumentException`을 발생시킨 후 애플리케이션 종료

- 5자 초과의 자동차 이름을 입력한 경우
- 자동차 이름을 입력하지 않은 경우 (`null`, `“”` , `“ “`)
- 이동 시도 횟수가 0 또는 음수인 경우
- 이동 시도 횟수가 숫자 외의 문자인 경우
- 이동 시도 횟수를 입력하지 않은 경우

<br>

## 테스트

- 정상 동작
    - 자동차 이름을 쉼표(,)를 기준으로 구분한다.
    - 이동 값이 4 미만인 경우, 전진하지 않는다.
    - 이동 값이 4 이상인 경우, 전진한다.
    - 전진한 횟수만큼 하이픈(-)을 출력한다.
    - 여러 번의 시도 결과로 우승자를 찾는다.
    - 모든 자동차가 전진하지 못하면, 모두 공동 우승한다.


- 경계
    - 이동 횟수는 1 이상의 자연수만 허용한다.
    - 무작위 값이 3인 경우, 전진하지 않는다.
    - 무작위 값이 4인 경우, 전진한다.

    
- 예외
    - 자동차 이름이 5자 초과인 경우, IllegalArgumentException 이 발생한다.
    - 자동차 이름이 null이거나 공백 또는 비어있는 경우, IllegalArgumentException 이 발생한다.
    - 이동 시도 횟수가 0 또는 음수인 경우, IllegalArgumentException 이 발생한다.
    - 이동 시도 횟수가 숫자 외의 문자인 경우, IllegalArgumentException 이 발생한다.
    - 이동 시도 횟수를 입력하지 않은 경우, IllegalArgumentException 이 발생한다.
